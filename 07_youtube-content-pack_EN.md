TEMPLATE #2 — VIDEO SCRIPT WRITING

USE THIS to write compelling video scripts.

PROMPT:
"Write video script for: [DESCRIBE VIDEO]

Structure:

1) Hook (first 5 seconds - problem or curiosity)
2) Intro (who you are, why you're qualified)
3) Problem statement (why this matters, data/example)
4) Solution walkthrough (step-by-step, show not tell)
5) Real-world example (concrete case study)
6) Common mistakes (what NOT to do)
7) Key takeaway (one main point to remember)
8) Call-to-action (subscribe, like, comment, link)
9) Outro (thank you, tease next video)

Video topic: [E.g., How to structure React components]
Duration: [10 minutes]
Tone: [Casual / Professional / Enthusiastic]
Visuals: [Screen recording / B-roll / Talking head / Mixed]

Provide:
- Full video script with timings
- Visual cues (what to show when)
- On-screen text / graphics
- Speaker notes and pacing
- Multiple hook options
- CTA variations"

ARVEN TIP: Write for the ear, not the eye. Conversation beats reading.
