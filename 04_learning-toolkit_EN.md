TEMPLATE #1 — CURRICULUM DESIGN

USE THIS when building a course from scratch.

PROMPT:
"Design a curriculum for: [DESCRIBE COURSE]

Define:

1) Learning objectives (what learners can do after)
2) Target audience (skill level, background)
3) Course structure (modules, units, lessons)
4) Time estimate (hours per topic)
5) Prerequisites (what they need to know first)
6) Key concepts (the 20% that matter 80%)
7) Learning sequence (build from simple to complex)

Course topic: [E.g., Python for Beginners]
Duration: [8 weeks / 40 hours / self-paced]
Delivery: [Video / Interactive / Text / Mixed]

Provide:
- Curriculum outline (hierarchical structure)
- Time allocation per topic
- Learning progression
- Success metrics for each module"

ARVEN TIP: 80% of learning comes from 20% of content. Identify that 20%.

TEMPLATE #2 — CONTENT STRUCTURE

USE THIS to organize lessons effectively.

PROMPT:
"Structure lesson content for: [DESCRIBE TOPIC]

Include:

1) Hook (why learners should care - 2 min)
2) Learning objectives (3-5 specific outcomes)
3) Key concept explanation (simple to complex)
4) Real-world examples (3-5 concrete cases)
5) Interactive practice (hands-on exercises)
6) Common mistakes (what NOT to do)
7) Review and recap (summarize key points)
8) Next steps (what's next in the course)

Topic: [E.g., Database Normalization]
Audience: [Beginners / Intermediate / Advanced]
Format: [Video / Article / Interactive]

Provide:
- Lesson outline with timing
- Content for each section
- Practice exercises with solutions
- Common misconceptions to address"

ARVEN TIP: Story > facts. Use examples before abstract concepts.

TEMPLATE #3 — VIDEO SCRIPTING

USE THIS for video lessons that engage.

PROMPT:
"Write a video script for: [DESCRIBE TOPIC]

Include:

1) Hook (first 5 seconds - why this matters)
2) Problem statement (what problem does this solve)
3) Solution explanation (step-by-step walkthrough)
4) Visual cues (where to show graphics, demos, b-roll)
5) On-screen text (key points to display)
6) Pacing (faster for excitement, slower for complex)
7) Call-to-action (what to do after video)

Topic: [E.g., React Hooks]
Duration: [5 min / 10 min / 20 min]
Tone: [Casual / Professional / Enthusiastic]

Provide:
- Full video script with timings
- Visual directions (what to show when)
- Speaker notes (delivery tips)
- Slide/graphic requirements"

ARVEN TIP: 1000 words of reading = 6 min video. Keep videos under 15 min.

TEMPLATE #4 — ASSESSMENT DESIGN

USE THIS to measure what learners actually learned.

PROMPT:
"Design assessments for: [DESCRIBE COURSE/MODULE]

Create:

1) Knowledge checks (multiple choice, quick recall)
2) Skill practice (hands-on exercises with solutions)
3) Projects (real-world application of concepts)
4) Quizzes (deeper understanding, not just facts)
5) Capstone project (synthesis of entire course)
6) Rubrics (grading criteria, clear expectations)
7) Feedback mechanism (how learners know if correct)

Course: [E.g., Python Bootcamp]
Assessment types: [Auto-graded / Instructor-graded / Peer-graded]

Provide:
- Assessment for each module
- Test questions (with answer keys)
- Project briefs with rubrics
- Grading scale and expectations
- Feedback templates"
